----------------------------------------------------------
  - URL: https://yczwdkkuaitlbvtskmsf.supabase.co/functions/v1/api
  - フロントは旧GASと同じ { action, ...payload } POST 形式で呼ぶ (完全互換)。

    Supabase ダッシュボード or CLI (supabase functions deploy api) or

----------------------------------------------------------
3. フロントエンド
----------------------------------------------------------
  - app.js 先頭の API_URL に上記 Edge Function の URL を設定済み。
  - index.html をブラウザで開くだけで動作 (キオスク型UI・ログイン不要)。
  - PWA: service_worker.js が code assets を network-first で配信するので、
    デプロイ後はページを一度リロードすれば最新版に切り替わる。
    ※ 移行直後はキオスク端末で必ず1回リロードすること
      (リロード前の端末は旧GAS=スプレッドシートに書き込んでしまう)。

----------------------------------------------------------
5. 運用メモ
----------------------------------------------------------
  * タイムゾーンは Asia/Ho_Chi_Minh (UTC+7) で記録。
  * 打刻の状態遷移: 未出勤 → 出勤 → (休憩開始 ⇄ 休憩終了)* → 退勤。
    退勤後は同日中の再出勤も可 (スプリットシフト対応)。
  * データの手修正は Supabase ダッシュボードの Table Editor から行える。
  * users テーブルには個人情報 (生年月日・ID番号・銀行口座など) が含まれる。
    Supabase プロジェクトへの招待は最小限にすること。
  * バックアップ: Supabase の自動バックアップ (無料枠は日次) に加え、
    ダッシュボードから CSV エクスポートも可能。
  * Supabase 無料プランはアクセスが1週間無いとプロジェクトが一時停止する。
    停止したらダッシュボードから Restore すれば再開できる (データは残る)。

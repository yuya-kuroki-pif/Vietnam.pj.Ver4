4.5 スプレッドシートへの自動転記 (ミラー/バックアップ)
----------------------------------------------------------
  Supabase の全データを Google スプレッドシートへ定期転記できる。
  手順は `SyncScript.gs` のファイル冒頭コメントを参照:
    1) 新しいスプレッドシートを作成 (旧「Vietnam勤怠DB」は使わない)
    2) 拡張機能 → Apps Script に SyncScript.gs を貼り付け
    3) EXPORT_TOKEN を設定 (トークンはリポジトリに含めない。管理者に確認)
    4) syncAll を一度実行 → setupTrigger で6時間ごとの自動同期を開始
  ミラーは読み取り専用。シートを編集しても Supabase には反映されない。

5. 運用メモ
----------------------------------------------------------
  * タイムゾーンは Asia/Ho_Chi_Minh (UTC+7) で記録。
  * 打刻の状態遷移: 未出勤 → 出勤 → (休憩開始 ⇄ 休憩終了)* → 退勤。
    退勤後は同日中の再出勤も可 (スプリットシフト対応)。
  * 従業員情報 (氏名・所属店舗・時給/日給など) はマスタ画面の
    各ユーザーカードの「✎」ボタンからアプリ内で編集できる (2026-09-02 追加)。
  * 人件費の内訳 (2026-09-24 追加):
      - 従業員マスタの「給与・手当」欄に 月給(参考) / 交通費 / 駐車場代 /
        社会保険 会社負担 / その他手当 を月額で登録できる
        (users.salary / transportationExpenses / parkingFee / socialInsurance / otherAllowance)。
      - 基本給 = 日給×出勤日数 (優先) または 時給×労働時間。月給者は概算日給を日給欄に入れる。
      - 月額項目は暦日で日割り (月額 ÷ 当月日数 × 集計範囲の日数、ただし本日まで) し、
        所属店舗の人件費に自動計上。当月に出勤の無い従業員には計上されない (2026-10-07 改定)。
      - 勤怠集計 (画面・CSV) とダッシュボードの人件費カードに内訳が出る。
        ダッシュボードの「その他人件費 (手入力)」は賞与・臨時スタッフなど
        マスタに載せられない分だけを入れる運用にする。
      - 社会保険 会社負担 = 月給 × 率 で自動算出 (users.socialInsuranceRate、既定 28%。
        従業員ごとに変更可)。給与形態が月給制の従業員のみ対象。旧 users.socialInsurance 列は未使用。
  * 原価 (ダッシュボード) の集計ルール (2026-09-24 改定):
      - 原価は税抜で集計 (仕入は税抜単価×数量、小口現金は税込金額を税率で割戻し)。
        売上の分母 (税抜) と基準をそろえた。
      - 棚卸方式 (前月棚卸 + 仕入 − 当月棚卸) は前月・当月の両方に棚卸がある区分だけ適用。
        片方しか無い月は仕入ベースに戻る。適用中はカードに「棚卸反映済」と出る。
      - 原価率 (合計) はフード+ドリンクのみ。消耗品・サービス料・カテゴリ未設定の仕入は
        「その他仕入」として別行に表示し、利益計算にだけ使う。
      - 合計の目標原価率はフード/ドリンク目標を売上構成比で加重した値。
      - 既知の差: 棚卸の評価単価は在庫マスタの前回単価 (税込) なので、仕入 (税抜) と
        厳密には数%ずれる。棚卸を本格運用する際に税抜評価へ揃えること。
  * 勤怠管理画面の「⬇ CSV」で表示中の月の打刻データを出力できる
    (従業員未選択なら全員分)。
  * その他のデータの手修正は Supabase ダッシュボードの Table Editor から行える。
  * users テーブルには個人情報 (生年月日・ID番号・銀行口座など) が含まれる。
    Supabase プロジェクトへの招待は最小限にすること。
  * バックアップ: Supabase の自動バックアップ (無料枠は日次) に加え、
    ダッシュボードから CSV エクスポートも可能。
  * Supabase 無料プランはアクセスが1週間無いとプロジェクトが一時停止する。
    停止したらダッシュボードから Restore すれば再開できる (データは残る)。
